# RSS Survey Assistant

A Word add-in and Level 3 Building Survey template for the Residential Survey Standard (RSS).

- `taskpane.html`, `data.js`, `ooxml.js`, icons: the add-in sidebar, served by GitHub Pages
- `manifest.xml`: load this into Word to install the add-in
- `template/RSS_Level3_Template.docx`: the report template
- `source/`: scripts that rebuild the template and `ooxml.js` from `data.js`
- `SETUP.md`: installing and using it
